# Cyber Security Internship

## Overview

This repository contains my Cyber Security Internship tasks. The purpose of this internship is to develop practical cybersecurity skills through hands-on activities, security research, and technical documentation.

## Internship Objectives

* Learn cybersecurity fundamentals.
* Perform network scanning and security analysis.
* Understand common cyber threats and vulnerabilities.
* Practice ethical hacking techniques in a safe environment.
* Improve technical documentation and reporting skills.

## Tasks Included

### Task 1 – Basic Network Scanning with Nmap

* Installed and configured Nmap.
* Performed basic network scanning.
* Identified open ports and running services.
* Performed service version detection.
* Performed operating system detection.
* Documented security risks for identified services.
* Included screenshots and scan results.

### Task 4 – Research Report: Common Network Security Threats

* Studied common network attacks.
* Explained real-world examples.
* Provided mitigation techniques.
* Added comparison tables and references.

### Task 5 – Research Report: Social Engineering Attacks

* Explained phishing, pretexting, baiting, and related attacks.
* Included case studies.
* Provided prevention recommendations.

### Task 6 – Research Report: Importance of Patch Management

* Explained the patch management lifecycle.
* Discussed real-world incidents caused by unpatched systems.
* Recommended best practices for organizations.
